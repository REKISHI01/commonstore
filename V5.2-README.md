# Itemku Profit Management System V5.2 — Automation & Governance

V5.2 melanjutkan V5.1 dengan fokus pada otomasi yang tetap aman untuk Owner. Tidak ada aksi sensitif yang langsung mengubah harga atau diskon tanpa persetujuan.

## Fitur baru

### Automation Runner
- Menjalankan rule operasional secara manual dari Owner Dashboard.
- Membuat notifikasi baru dari rule stok, aging, SLA, margin, dan hot product.
- Perubahan sensitif hanya dibuat sebagai proposal Approval Center.
- Menyimpan histori 100 automation run terbaru.

### Approval Center
- Menampung rekomendasi perubahan harga dan aktivasi diskon.
- Alur: Pending → Disetujui/Ditolak → Diterapkan.
- Harga/diskon baru tidak pernah diterapkan sebelum Owner menyetujui lalu menekan Terapkan.
- Perubahan yang diterapkan tetap memakai saveProductsV sehingga delta sync cloud V4+ tetap digunakan.

### Scheduled Reports
- Jadwal Harian, Mingguan, dan Bulanan.
- Laporan dibuat otomatis ketika dashboard/PWA dibuka dan jadwal sudah jatuh tempo.
- Bisa Generate sekarang dan export JSON per laporan.
- Catatan: mode lokal tidak dapat mengeksekusi job ketika browser benar-benar tertutup. Untuk background scheduler 24/7 perlu server/cron terpisah.

### Maintenance Center
- Melihat pemakaian localStorage dan jumlah log V5.2.
- Safe Cleanup hanya membersihkan data UI/non-bisnis lama: notifikasi read >30 hari, log automation/report berlebih, dan approval resolved lama.
- Tidak menghapus order, produk, inventory ledger, PO, payout, dispute, atau data finansial.
- Export Maintenance Snapshot untuk troubleshooting.

### Backup/Recovery V5.2
Backup V5.2 menambahkan blok `v52`:
- approvals
- automationRuns
- reportSchedules
- scheduledReports

Recovery Center juga memulihkan blok tersebut bila ada.

### Final Control Center
Readiness V5.2 ikut memeriksa:
- approval sensitif yang masih pending
- scheduled report yang terlambat diproses

## Upgrade V5.1 → V5.2
1. Buat backup V5.1 terlebih dahulu.
2. Ganti source dengan V5.2.
3. Jalankan `pnpm install` bila dependency belum tersedia.
4. Jalankan `pnpm release:check` dan `pnpm typecheck`.
5. Untuk instalasi cloud baru gunakan `supabase/schema-v5.2.sql`.
6. Upgrade V5.1 → V5.2 tidak membutuhkan tabel bisnis Supabase baru karena data governance V5.2 disimpan lokal dan ikut backup JSON.
7. Buka Final Control Center dan pastikan tidak ada isu kritis.
