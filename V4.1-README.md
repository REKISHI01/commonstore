# Itemku Profit Management System V4.1

**Speed & Intelligence Update** di atas fondasi V4.0. Semua data lokal V4 tetap kompatibel; untuk fitur cloud baru jalankan schema V4.1.

## Fitur baru

1. **Order Kanban** — workflow Baru → Diproses → Menunggu → Selesai.
2. **Smart Restock V4.1** — weighted demand 7/14/30 hari, lead time, safety buffer, estimasi stok habis, dan saran jumlah restock.
3. **Product Performance Score** — skor 0–100 dari penjualan, margin, refund, dan kesehatan stok.
4. **Profit Simulator** — BEP, harga target, ROI, modal, omzet, dan profit untuk skenario sebelum stok/listing.
5. **Margin Guard** — warning saat harga produk berada di bawah BEP atau target margin; Bulk Edit juga tidak membiarkan harga hasil markup jatuh di bawah BEP.
6. **Bulk Edit Produk** — supplier, kategori, fee, status aktif, dan markup harga untuk banyak SKU.
7. **Worker Queue** — rekomendasi worker berdasarkan game + antrean; Auto Assign semua order Baru yang belum ditugaskan.
8. **Report Generator** — periode preset/custom, ringkasan bisnis, CSV, serta laporan HTML yang bisa Print / Save as PDF.

## Cloud V4.1

Tambahan cloud utama:
- RPC `assign_order_atomic` hanya untuk Owner.
- Validasi worker aktif, permission `canProcessOrders`, dan `allowed_games` dilakukan di database.
- Order yang sudah ditugaskan dikunci dari Worker lain selama masih aktif.
- Status `Menunggu` ditambahkan ke database dan RPC status order.

### Upgrade Supabase dari V4.0

Cara paling sederhana: jalankan **seluruh** `supabase/schema-v4.1.sql` di SQL Editor. File ini berisi schema V4.0 + upgrade V4.1 dan memakai pola `if not exists` / `create or replace` untuk upgrade bertahap.

Sebelum migrasi database produksi, tetap lakukan Backup & Export dari dashboard.


## Catatan Worker Queue

Agar Auto Assign cloud berfungsi, setiap Worker perlu:
- akun Supabase Auth,
- profile role `worker`,
- `active=true`,
- permission `canProcessOrders=true`,
- dan jika `allowed_games` diisi, game order harus termasuk dalam daftar tersebut.
