# Itemku Profit Management System V4.2

**Operations & Intelligence Update** di atas V4.1. Update ini tidak membutuhkan tabel Supabase baru; seluruh fitur memakai struktur data V4.1 yang sudah ada.

## Fitur baru V4.2

1. **Quick Order** — alur singkat untuk order WhatsApp/direct dengan preview omzet, profit, fee channel, dan stok setelah order.
2. **Auto Price Advisor** — rekomendasi harga untuk target margin 5–30%, mempertimbangkan modal, biaya lain, fee channel, dan fixed fee. Harga dapat diterapkan ke master produk dan masuk price history.
3. **Product Templates & Duplicate** — duplikasi produk sebagai template baru dengan stok 0, SKU unik, diskon dimatikan, lalu langsung edit.
4. **Customer Intelligence** — loyalty score, VIP/Loyal/Regular, AOV, refund rate, dispute aktif, dan risk score pelanggan.
5. **Sales Trend Radar** — membandingkan unit terjual 7 hari terakhir vs 7 hari sebelumnya dan menandai Naik/Baru/Stabil/Turun.
6. **Daily Operations** — checklist prioritas otomatis untuk order aktif, stok kritis, margin rendah, dispute, PO, dan settlement.
7. **Data Quality Center** — deteksi SKU kosong/duplikat, invoice kosong/duplikat, order historis tanpa master produk, serta mismatch stok-vs-ledger. Auto-fix hanya untuk perbaikan yang aman.
8. **Business Calendar** — kalender bulanan yang menggabungkan order selesai, profit, expense, PO, payout settlement, dan dispute.

## Upgrade dari V4.1

- Data V4.1 tetap kompatibel.
- Tidak ada migrasi database wajib.
- Untuk instalasi baru, gunakan `supabase/schema-v4.2.sql` (isinya schema V4.1 + penanda kompatibilitas V4.2).
- Backup data sebelum upgrade tetap disarankan.

## Catatan Data Quality

Tombol **Perbaiki Aman** hanya menormalisasi hal yang dapat diperbaiki tanpa menebak nilai bisnis: SKU kosong/duplikat, invoice kosong/duplikat, dan angka produk negatif jika berasal dari data lama. Mismatch ledger hanya dilaporkan untuk diperiksa manual.
