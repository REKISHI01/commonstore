# Itemku Profit Management System V2.1

V2.1 menambahkan mode cloud Supabase tanpa dependency npm tambahan. Mode lokal tetap tersedia sebagai fallback.

## Fitur baru V2.1
- Login Supabase untuk Owner dan Worker.
- Sinkronisasi produk dan order lintas perangkat.
- Owner/Worker melakukan refresh cloud otomatis setiap ±5 detik saat sesi cloud aktif.
- LocalStorage tetap menjadi cache/fallback bila internet atau Supabase bermasalah.
- Upload data lokal ke cloud dan tarik data cloud ke lokal dari menu **Cloud Sync**.
- RLS berbasis role `owner` / `worker`.
- Worker tidak bisa mengubah harga, modal, snapshot finansial, atau identitas order melalui database.
- Worker hanya mengubah status order dan stok yang terkait refund.

## Menjalankan lokal
```bash
pnpm install
pnpm dev
```
Buka `http://localhost:3000` untuk Owner dan `http://localhost:3000/worker` untuk Worker.

## Mengaktifkan Supabase
1. Buat project baru di Supabase.
2. Buka SQL Editor dan jalankan seluruh isi `supabase/schema-v2.1.sql`.
3. Di **Authentication > Users**, buat akun Owner dan Worker menggunakan email/password.
4. Salin UUID user yang dibuat, kemudian masukkan profile, contoh:
```sql
insert into profiles(id,name,role) values ('UUID_OWNER','Owner','owner');
insert into profiles(id,name,role) values ('UUID_WORKER','Worker 1','worker');
```
5. Salin `.env.example` menjadi `.env.local` dan isi:
```env
NEXT_PUBLIC_SUPABASE_URL=https://PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_ANON_KEY
```
6. Restart web.
7. Owner buka **Pengaturan > Cloud Sync**, login, lalu pilih **Upload lokal ke cloud** untuk migrasi pertama.
8. Worker membuka `/worker` dari perangkat lain dan login menggunakan email/password Supabase.

## Catatan keamanan
- Jangan memakai `service_role` key di browser. Web ini hanya membutuhkan anon key.
- Kebijakan RLS harus tetap aktif.
- V2.1 menyimpan access token Supabase di localStorage agar sesi tetap aktif. Untuk penggunaan publik/berskala besar, tahap berikutnya sebaiknya memindahkan sesi ke cookie httpOnly melalui server-side auth.

## Migrasi dari V2
Data V2 di browser tidak dihapus. Setelah Supabase aktif, login Owner lalu gunakan **Upload lokal ke cloud**. Snapshot order lama tetap dipertahankan.
