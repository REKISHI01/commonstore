# Itemku Profit Management System V5.1 — Resilience & Recovery

V5.1 mempertahankan seluruh fitur V5.0 FINAL dan menambah lapisan recovery/observability agar aplikasi lebih mudah didiagnosis dan dipulihkan ketika terjadi masalah di browser, cache, sync, atau backup.

## Yang baru

### Recovery Center
- Preview backup JSON sebelum restore.
- Restore diblokir bila ditemukan SKU/invoice duplikat, stok negatif, snapshot finansial rusak, atau struktur backup tidak dikenali.
- SHA-256 checksum untuk memeriksa integritas file.
- Auto-checkpoint sebelum restore.
- Recovery Vault berbasis IndexedDB, maksimal 5 checkpoint lokal dengan rotasi otomatis.
- Checkpoint dapat dipreview dan didownload.

> Recovery Vault berada di browser yang sama. Tetap simpan backup JSON eksternal di lokasi terpisah.

### Observability Center
- Tes `/api/health` + latency.
- Status cloud, realtime, browser online/offline, Service Worker, dan pending sync.
- Estimasi penggunaan storage browser.
- Client Error Journal maksimal 50 error lokal.
- Error JavaScript dan unhandled promise rejection otomatis dicatat tanpa mengirim data ke pihak luar.

### Audit & Evidence
- Filter audit berdasarkan pencarian dan tanggal.
- Export audit CSV.
- Export audit JSON + file SHA-256 untuk verifikasi integritas.

### Final Control Center V5.1
Readiness sekarang ikut memeriksa:
- Client Error Journal.
- Recovery checkpoint terakhir.

## Upgrade V5.0 FINAL → V5.1

1. Buat backup JSON V5.0 terlebih dahulu.
2. Ganti source dengan V5.1.
3. Database tidak memerlukan tabel bisnis baru.
4. Jika ingin instalasi/schema referensi terbaru, gunakan `supabase/schema-v5.1.sql`.
5. Jalankan `pnpm install`, `pnpm release:check`, `pnpm typecheck`, dan `pnpm build`.
6. Buka **Recovery Center** dan buat checkpoint pertama.
7. Buka **Observability Center**, pastikan health server normal dan Pending Sync = 0.
8. Buka **Final Control Center** dan pastikan tidak ada isu Kritis.

## Catatan keamanan

Recovery Vault tidak menggantikan backup eksternal/cloud. Jika browser storage dihapus atau perangkat rusak, checkpoint IndexedDB juga dapat hilang. Untuk backup penting, download JSON V5.1 dan simpan di perangkat/lokasi lain.
